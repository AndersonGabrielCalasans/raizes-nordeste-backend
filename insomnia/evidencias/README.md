# Evidências dos testes

Esta pasta reúne capturas dos testes executados no Insomnia e o registro da consulta de auditoria no PostgreSQL. Os nomes identificam cada cenário, como `T05-criar-pedido-aprovacao.png`, `T06-pagamento-aprovado.png` e `T10-pagamento-recusado.png`.

As capturas apresentam o nome da requisição, o status HTTP e os campos relevantes da resposta. Os resultados estão registrados em [resultados.md](../resultados.md), e o procedimento completo está no [guia de testes](../../docs/testes/testes.md).

Os dados são fictícios e pertencem ao ambiente local de teste. A captura de login contém um token temporário dessa execução.
